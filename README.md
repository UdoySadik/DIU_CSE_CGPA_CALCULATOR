# 🎓 DIU_CSE_CGPA_CALCULATOR

A modern, fast, and responsive Web Application built specifically for **Daffodil International University (DIU)** Computer Science & Engineering (CSE) students to calculate, track, and plan their SGPA and CGPA with a premium dark glassmorphism UI/UX.

---

## 🌟 Key Features

- **🔐 Student Authentication & Guest Mode**:
  - Secure Student ID login & registration with persistent `localStorage` storage (DIU ID format e.g., `251-15-065`).
  - Quick **Guest Mode** for instant calculations without account registration.

- **📊 Interactive Dashboard**:
  - Displays overall CGPA, grade standing, and completed credits out of **154.5 total curriculum credits**.
  - Quick action shortcuts to all application tools.

- **🧪 Theory Course Result Calculator**:
  - Calculate total marks out of 100 based on Attendance (7), Assignment (5), Presentation (8), Quizzes (Avg of 15), Midterm (25), and Final Exam (40).
  - Displays predicted grade points and letter grades (A+, A, A-, B+, B, C, D, F).

- **📝 Semester SGPA Calculator**:
  - Pre-configured course curriculum & credit hours for all 12 DIU CSE Semesters (**L1T1 to L4T3**).
  - Grade point entry (0.00 - 4.00) per course with instant weighted SGPA calculation.
  - Automatically saves semester records for registered student accounts.

- **📜 SGPA Records Management**:
  - Detailed table showing saved semester GPAs, credits, and letter grades.
  - Edit or delete semester entries.

- **🧮 Manual CGPA Calculator**:
  - Directly enter SGPAs across any desired semesters for instant cumulative GPA calculation.

- **🎯 Target CGPA Planner**:
  - Input your target graduation CGPA and remaining semesters.
  - Calculates the exact average SGPA required in upcoming semesters to achieve your goal.

- **📄 Result Summary Exporter**:
  - Download a formatted `.txt` transcript summary report with one click.

---

## 🛠️ Technology Stack

- **Frontend**: HTML5, Vanilla JavaScript (ES6+)
- **Styling**: Custom CSS3 (Glassmorphism design, Dark Mode, CSS Variables, Responsive Layout)
- **Icons & Fonts**: FontAwesome 6, Google Fonts (*Outfit* & *Plus Jakarta Sans*)
- **Storage**: Browser `localStorage` (Zero backend dependency)
